---
description: Add a record: queue, agent, shift, break, leave request, interval, adherence day or forecast adjustment.
---

Read docs/cli.md and the migration. Put the supplied fields in a private JSON file under imports/, then run `npm run wfm -- add <type> --data=imports/record.json`. Codes are accepted for queue_id, agent_id and shift_id. Read the record back. Never invent figures.
