Read docs/compliance.md. Run `npm run wfm -- compliance`. Report as a table: rule, agent, shift, what the data shows, the source. Order by date. For each finding draft the fix (move a break with /move-shift, lengthen a shift, publish a roster) and wait for a yes. Nothing here is legal advice: which award or agreement covers each person is the employer's call, recorded in the agent's award field.
