description: Today so far against forecast, and whether the rest of the day is short if the drift holds.
---

Run `npm run wfm -- intraday`. Report variance, service level so far, and short half hours on plan and after reforecast. If a queue runs 10 per cent or more over, run `npm run wfm -- staffing --date=<today> --queue=<code>` and name the half hours to cover. Suggest options (move breaks, pull training, offer extra hours from /under-hours) and wait for a yes before any change.
