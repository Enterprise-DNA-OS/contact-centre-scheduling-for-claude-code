---
description: Move or resize a shift. A published shift records the change, its basis and the notice given.
---

Read the shift with `npm run wfm -- shift <code>`. Ask for the new times, the basis (notice, agreed or emergency) and the reason. Run `npm run wfm -- move-shift <code> --start="YYYY-MM-DD HH:MM" --end="YYYY-MM-DD HH:MM" --basis=<basis> --reason="<why>" --by="<planner>"`. Breaks move with the start. Report the notice hours and any rule finding the move creates. Tell the planner the agent has not been told: offer /draft-roster.
