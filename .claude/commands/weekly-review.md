description: The Monday workforce review, written from attention, coverage gaps, service level, leave and forecast accuracy.
---

Run `npm run wfm -- attention`, `npm run wfm -- coverage-gaps` and `npm run wfm -- forecast-accuracy`. Write five lines: what went wrong last week, what is short this week, the decisions waiting (leave, roster changes), the rule findings, one forecast fix. Then run /draft-weekly to save it.
